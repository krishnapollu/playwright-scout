# playwright-scout

Static-analysis CLI and agent skill for finding existing Playwright tests, page objects, helpers, and fixtures.

```sh
npx playwright-scout map
npx playwright-scout find login
npx playwright-scout show LoginPage.login
npx playwright-scout install-skill
```

Node.js 20 or newer is required. See the [project README](https://github.com/krishnapollu/playwright-scout#playwright-scout) for options and known limitations.
