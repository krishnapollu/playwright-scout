# Contributor Covenant Code of Conduct

This project adopts [Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) for all project spaces and for people representing the project publicly. Its standards, enforcement responsibilities, and enforcement guidelines apply here.

Report a concern through a GitHub issue or privately to `<MAINTAINER EMAIL>`. For sensitive reports, use the email placeholder once the maintainer has replaced it; a public issue is visible to everyone. Maintainers will review reports promptly and fairly and respect reporters' privacy and security.
